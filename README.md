# Desktop soundboard
A simple app to float over desktop apps and play audio files loaded from your PC, to act as a soundboard when you are sharing your screen.

<img width="1153" height="674" alt="image" src="https://github.com/user-attachments/assets/1d12f84a-6bfd-43bb-bebd-2e60c0c232ea" />
A useful overlay for screen-sharing or just playing sounds!

## Usage:
Extract windows .zip file and run exe to use. No installer, just run the executable. Try not to move or delete audio files once you add them to the app, since this will make it impossible to play that file until you remake it. Right-click on sounds to remove them from the app.
