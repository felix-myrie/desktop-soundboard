# Desktop soundboard
A simple app to float over desktop apps and play audio files loaded from your PC, to act as a soundboard when you are sharing your screen.

A useful overlay for screen-sharing or just playing sounds! Add any .mp3 sound effect and play as many sounds as you like, all at once!

## Installation:
Download the latest version of the app (currently only available for Windows) from the [releases](https://github.com/felix-myrie/desktop-soundboard/releases) page of the repository. Please follow these instructions to get started using the app:
- Extract the desktop-soundboard.zip archive into an empty folder.
- Run the .exe file from this extracted folder. 
- The Application will start! Please read the instructions in the main repo to understand how to use the app if you are unclear on how to use it!
- (Optional): Add a shortcut to the app on the desktop by right-clicking, clicking add shortcut, and navigating to the location of the .exe file, and selecting it. This means you can open the app more easily without having to navigate folders.

### Settings:
When you download the app, you will be greeted with the settings menu, where you can adjust basic settings about the app to make it easier to use. You may want to set an opaque background, especially if you use light mode, and you can choose the colour of this background.
You can re-open the menu at any point!

<img width="476" height="634" alt="image" src="https://github.com/user-attachments/assets/9e63446a-72b8-45e1-b748-2b64c33caacf" />

### Main App:
Once you've finished with that, you will enter this main page. Press the button for a certain sound to play that sound. Right click on a sound you would like to remove (you will have to confirm before removing). The app comes with sounds that cannot be removed by default, but you can disable these sounds, as well as controlling other settings, in the Settings menu. Click the cog icon to open this menu.

### Adding sounds:
If you want to add a new sound from your recordings or the internet, make sure it is a .mp3 file, and then use the plus icon to add the sound. You will be able to choose the file from your computer, choose a display name and emoji icon and save the sound. Use an emoji keyboard to find emojis, like the Windows+Period shortcut, or otherwise you can find emojis on a keyboard like [Emojipedia](https://emojipedia.org/). Please **don't move or delete the audio file** once you have chosen it, otherwise the app will be unable to play it. There is no limit to the number of sounds that can be added so have fun!
